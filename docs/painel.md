# Painel web

Interface em português para explorar a base tratada do OECD.AI AIM.

Filtros: Mundo, Brasil, país e categorias A, B, C e D. Um registro pode pertencer a mais de uma categoria.

Formato de data/registros.json: id, data, pais, titulo, tipo, A, B, C, D. A/B/C/D podem ser booleanos ou 0/1.
